# 从结构式计算 OSA-β-CD 的 HLB，并用 Tween 80 作锚点核验

> 一个用 AI 完成"文献公式提取 → 代码复现 → 原文核验 → 应用到真实化合物"的文献阅读案例。
> 挑战赛方向：结论核查 / 方法分析。

## 0. 一句话结论

用 Griffin(1954) 质量分数法计算，**OSA-β-CD 酸型在 DS≈2 时 HLB≈15.8，与 Tween 80（HLB=15）接近**；DS 越高越亲油（HLB 降到 11 左右）。用 Davies(1957) 基团法计算则全部 >30（钠盐型高达 149），说明 **Davies 法对该类多羟基/多取代大分子失效**。两种方法的差异本身，就是"HLB 从结构式计算必须有锚点"的直接证据。

## 1. 问题与方法

### 1.1 阅读问题

不同文献给出不同的 HLB 计算公式：Griffin(1954) 用"亲水部分质量分数"，Davies(1957) 用"基团贡献"。对同一表面活性剂，二者结果可能差很多。我要解决的具体问题是：

> 如何从 OSA-β-CD（辛烯基琥珀酸 β-环糊精）的结构式可靠地计算其 HLB，
> 并在不同公式给出不同数值时，用公认值 HLB≈15 的 Tween 80 作锚点来核验。

### 1.2 为什么用这个方法

HLB 是半经验标尺，不是物理常数。它没有一个"唯一真值"，只有"在某公式/某标尺下的值"。因此：
1. 先到**原始文献**拿公式和基团数（而非教科书转述），避免二传误差；
2. 用**代码实现**，让计算可复现、可审计；
3. 用**已知锚点 Tween 80** 先验证公式提取与实现是否正确（Griffin 原文给 15.0，Davies 原文给 15.8）；
4. 再对目标物做**同公式的相对比较**，而不是把不同公式的绝对值互比。

### 1.3 关键取舍

- 目标物 OSA-β-CD 是"多糖骨架上接疏水辛烯基 + 亲水羧基"的两亲大分子，且**取代度 DS 是可变的**（1–7），因此必须按 DS 逐点计算，而不是一个固定结构。
- 酸型(-COOH)与钠盐型(-COONa)的亲水性差异很大，要分开算。
- 不预设"哪个公式对"，而是同时用 Griffin 与 Davies，把适用边界讲清楚。

## 2. 真实案例与结果

### 2.1 结构与分子量

- β-CD：C42H70O35，MW≈1134.99，7 个葡萄糖单元、21 个游离 OH。
- OSA = 2-辛烯-1-基琥珀酸酐（C12H18O3，MW≈210.27）。开环与 CD 的 OH 成半酯：每取代净加 C12H18O3，同时引入 1 个游离 -COOH；钠盐型为 -COONa（每取代净加 C12H17O3Na）。
- 因此 DS=n：
  - 酸型：C(42+12n) H(70+18n) O(35+3n)
  - 钠盐型：C(42+12n) H(70+17n) O(35+3n) Na_n

化合物来源：Ke et al. 2020 报道用 2-octen-1-ylsuccinic anhydride 改性 β-CD 制得"octenyl succinic-β-cyclodextrin (OCD)"，并指出 OSA 引入疏水链(-CH2-CH2-)与电荷(COO⁻)。 [Ke et al. 2020](https://www.mdpi.com/1420-3049/25/3/654)

### 2.2 锚点核验（先算 Tween 80）

| 方法 | Tween 80 | 出处 |
|---|---|---|
| Griffin(1954) | **15.0**（±1） | 原文 Table 1, p.255 |
| Davies(1957) | 实验 15；基团法 **15.8** | 原文 Table II, p.430 |

另：Davies 法对简单分子（正丁醇=7.0、乙醇=7.9、油酸=1.0）可与原文 Table II 精确复现，证明公式与基团数提取无误（见 `data/anchor_tween80_verification.md`）。

### 2.3 OSA-β-CD 的 HLB（DS=1–7，酸型 / 钠盐型）

**方法 A — Griffin 质量分数法 `HLB = 20 × Mh/M`**
（亲水部分 = β-CD 核心 + n 个游离羧基；亲油部分 = 辛烯基链 + 琥珀酰骨架 + 酯键）

| DS | 酸型 HLB | 钠盐型 HLB | 酸型 MW | 钠盐型 MW |
|---|---|---|---|---|
| 1 | 17.54 | 17.58 | 1345.25 | 1367.24 |
| 2 | **15.75** | 15.87 | 1555.52 | 1599.49 |
| 3 | 14.39 | 14.59 | 1765.79 | 1831.74 |
| 4 | 13.31 | 13.60 | 1976.06 | 2063.99 |
| 5 | 12.44 | 12.80 | 2186.33 | 2296.24 |
| 6 | 11.73 | 12.16 | 2396.60 | 2528.49 |
| 7 | 11.13 | 11.62 | 2606.87 | 2760.74 |

**方法 B — Davies 基团贡献法 `HLB = 7 + ΣH − 0.475n`**

| DS | 酸型 HLB | 钠盐型 HLB |
|---|---|---|
| 1 | 43.00 | 60.00 |
| 2 | 40.85 | 74.85 |
| 3 | 38.70 | 89.70 |
| 4 | 36.55 | 104.55 |
| 5 | 34.40 | 119.40 |
| 6 | 32.25 | 134.25 |
| 7 | 30.10 | 149.10 |

### 2.4 结果解读（含核查发现）

1. **Griffin 法**落在 0–20 标尺内、物理合理：DS 越大 HLB 越低（越亲油），DS≈2 酸型 HLB≈15.8，与 Tween 80（15.0）相近。
2. **Griffin 法几乎区分不出酸型/钠盐型**（差 0.04–0.5）：因为它只看质量分数，不反映 -COO⁻ 的离子性。这是 Griffin 法的固有盲区（原文也写明离子型表面活性剂不适用质量百分比）。
3. **Davies 法全部 >30、钠盐型高达 149**：明显失标。原因是 Davies 的基团数（尤其 -COONa=19.1、-OH=1.9）是为**单头基小分子表面活性剂**标定的，线性外推到"21 个 OH + 多个电荷"的大分子会失效；Davies 原文也提醒过"这些值对很大分子不成立"（如 200 个 EO 单元）。
4. **酸/钠盐差异**：Davies 捕获到了（-COONa 19.1 vs -COOH 2.1）但过度放大；Griffin 完全忽略。真实差异介于两者之间。

### 2.5 核查结论

- **推荐口径**：对 OSA-β-CD 用 **Griffin 质量分数法**（与 Tween 80=15 同标尺），结论是"酸型 DS≈2 时与 Tween 80 亲水亲油平衡相当；DS 增大则更亲油"。
- **锚点必须与方法绑定**：Tween 80 在 Griffin 标尺下是 15.0，在 Davies 标尺下是 15.8。若拿 Davies 算出的 OSA-β-CD 直接和"15"比，会得出"OSA-β-CD 比 Tween 80 亲水 2–10 倍"的错误结论。
- **方法适用边界**：Griffin 适合非离子/弱电离两亲物；Davies 适合单头基小分子（含离子型），不适合多取代、多羟基大分子。

## 3. 复现步骤与材料

### 3.1 环境与依赖

- 仅需 Python 3（标准库，无第三方依赖）；本案例实际数值用 PowerShell 独立复核过。
- 文件：`code/hlb.py`（两种方法+基团数）、`code/osa_beta_cd_hlb.py`（OSA-β-CD 计算）。

### 3.2 操作步骤

1. 读取原始文献片段（`papers/`），核对公式与基团数（见第 4 节引用）。
2. 运行 `python code/hlb.py` → 自检正丁醇/乙醇与 Davies 原文 Table II 一致。
3. 运行 `python code/osa_beta_cd_hlb.py` → 输出 DS=1..7 酸型/钠盐型的 Griffin 与 Davies 值。
4. 与本文第 2.3 节表格核对；与 Tween 80 锚点（Griffin 15.0 / Davies 15.8）做同公式比较。

### 3.3 结果检查方法

- Davies 实现是否正确：正丁醇=7.0、乙醇=7.9、油酸=1.0（必须匹配 Davies 原文 Table II）。
- 锚点是否复核：Griffin 原文 Table 1 的 Tween 80=15.0；Davies 原文 Table II 的 Tween 80=15.8。
- 量纲/单位：HLB 无量纲；MW 用 g/mol；DS 为平均取代基团数。

## 5. 局限

- OSA-β-CD 的实际 DS 需由滴定（酸型）或 NMR 测定，本文未做实测，只按给定 DS 计算。
- HLB 本身是半经验量，Griffin 法 ±1 的不确定性大于本表部分小数位差异；酸/钠盐型的 Griffin 差异（<0.5）在实际中可能不可分辨。
- Davies 法对多取代大分子的失效是"外推失效"，不代表基团数本身错误。
